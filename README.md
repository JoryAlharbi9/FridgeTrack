# FridgeTrack

**Track Your Fridge, Save Your Food**

FridgeTrack is a full-stack web application that helps users track food items, quantities, categories, and expiry dates to reduce food waste.

## Features

- Add / Edit / Delete food items
- Expiry status: 🟢 Safe · 🟡 Expiring Soon · 🔴 Expired
- Categories & quantities
- Dashboard summary
- Input validation & sanitization

## Technologies

HTML · CSS · JavaScript · Node.js · Express · MySQL · Git/GitHub
